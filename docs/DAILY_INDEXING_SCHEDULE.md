# جدول الفهرسة اليدوية اليومية — DevTol (10 روابط يومياً)

> **الهدف:** إدخال أهم صفحات الأدوات في طابور الأولوية السريعة (Priority Crawl Queue) في Google Search Console لتخطي مرحلة الانتظار وفهرستها خلال 24 ساعة.

## طريقة الاستخدام اليومية (تستغرق 3 دقائق):
1. افتح [Google Search Console](https://search.google.com/search-console).
2. في شريط البحث العلوي: ضع الرابط واضغط `Enter`.
3. اضغط **اختبار عنوان URL المنشور** (Test Live URL).
4. اضغط **طلب الفهرسة** (Request Indexing).
5. كرر نفس العملية مع الـ 10 روابط المخصصة لليوم.
